# Releases

Install the latest release from PyPI:

```sh
pip install --upgrade mkdocs-sumi
```

Sumi follows [semantic versioning](https://semver.org/). Until 1.0, minor versions may change template blocks; configuration keys and Markdown syntax stay compatible.
