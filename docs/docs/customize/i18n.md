# Languages

Sumi's interface — buttons, labels, the search palette, dates and default callout titles — is available in 13 languages.

```yaml title="mkdocs.yml"
theme:
  name: sumi
  locale: de
```

| Code | Language | | Code | Language |
| --- | --- | --- | --- | --- |
| `en` | English | | `ko` | Korean |
| `zh` | Simplified Chinese | | `pt_BR` | Brazilian Portuguese (`pt` too) |
| `zh_TW` | Traditional Chinese (`zh_HK` too) | | `ru` | Russian |
| `de` | German | | `it` | Italian |
| `fr` | French | | `ar` | Arabic, right to left |
| `es` | Spanish | | `he` | Hebrew, right to left |
| `ja` | Japanese | | `pl` | Polish |
| `th` | Thai | | | |

A regional code uses its language: `de_AT` gets German, `zh_CN` Simplified Chinese.

Coming from Material for MkDocs? Sumi also reads Material's `theme.language`, so the interface stays in your language after you switch themes.

## Right-to-left languages

For Arabic and Hebrew the page is marked `dir="rtl"` and the whole layout mirrors: the sidebar moves to the right, the table of contents to the left, the mobile menu slides in from the right and arrows point the other way. Code blocks, inline code and file trees stay left to right.

## CJK typography

When the page language is Chinese, Japanese or Korean, Sumi uses a system font stack suited to the script, a slightly larger line height and no letter-spacing on headings. Search matches CJK text by substring (see [Search](search.md#chinese-japanese-and-korean)).

## Callout titles

Default callout titles follow the language: `> [!TIP]` is titled *Tip* in English and *提示* in Chinese. A custom title is always used as written.

## Multilingual sites

With MkDocs NG 1.11 or later, one `mkdocs.yml` holds every language. The first language is built at the root of the site and the others into `/zh/` and so on; each one can change any setting, such as `site_name` or `nav`. Sumi takes its interface language from each language's code.

```yaml title="mkdocs.yml"
site_url: https://example.com/

languages:
  en: English
  zh:
    name: 简体中文
    site_name: 我的项目
    nav:
      - 首页: index.md
      - 指南: guide.md
```

Put each translation next to the original page, as `guide.zh.md` next to `guide.md`, or give the language a folder of its own with `docs_dir: docs-zh`. `mkdocs build` builds every language and `mkdocs serve` previews them all; add `--language zh` to work on one.

What Sumi does on such a site:

- The **language menu** in the header, and the *Switch to …* commands in the command palette, link to the same page in the other language.
- A page that isn't translated yet is shown in the default language, with a **note at the top** that says so. Its text is marked with its own `lang`, so screen readers and browsers read it in the right language.
- Each page lists its translations with `<link rel="alternate" hreflang="…">`, so search engines show readers the version in their language.
- Search, `llms.txt` and the print edition are built for each language.

## Bilingual view

On a page that has a translation, the page actions get a **bilingual view** button (and <kbd>b</kbd> on the keyboard). It opens the page and its translation side by side, full window. Scrolling one side brings the other to the same section, so a reader can check a translation or read in a language they are learning. On a phone the two languages are tabs.

The two sides are the built pages themselves, so every component, diagram and code block works as usual, and nothing extra is built. Untranslated pages don't offer the view. Sections line up by their heading ids, so give translated headings the original's id — `## 安装 {#install}` — as this site does. Back, <kbd>Esc</kbd> and the close button leave the view; analytics count only the page that opened it.

Turn it off with `bilingual_view: false` under `theme:`.

See [Multi-language Sites](https://mkdocs-ng.org/user-guide/multi-language-sites/) in the MkDocs NG docs for all the settings. This site and [sumi-starter](https://github.com/mkdocs-ng/sumi-starter) are built this way.

With an older MkDocs, build one site per language and link them with `extra.alternate`; see [Navigation](navigation.md#languages).

## Adding a language

Interface strings live in one Python file, `mkdocs_sumi/i18n.py`. A missing string falls back to English. The translations other than English and Chinese were written for this release and wait for review by native speakers: corrections and new languages are welcome as pull requests.
