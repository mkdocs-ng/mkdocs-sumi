## 站点列表 {#the-sites}

| 站点 | 简介 | 用到的 Sumi 功能 |
| --- | --- | --- |
| [Sumi](https://sumi.mkdocs-ng.org/zh/) | 就是本站 | 首页、文档、卡片式博客、发布记录、打印版、中英双语和双语对照、`llms.txt` |
| [MkDocs NG](https://mkdocs-ng.org/) | 持续维护的 MkDocs | 带数据的首页、用户指南和开发者指南、对比页面、发布说明 |
| [MkDocs Catalog](https://catalog.mkdocs-ng.org/) | MkDocs 插件目录 | 带数据的首页、卡片、每周重新生成的大表格 |
| [Sumi 入门模板](https://mkdocs-ng.github.io/sumi-starter/zh/) | 可以直接复制的模板仓库 | 中英双语的首页、指南、参考、发布记录和博客，部署在 GitHub Pages |
| [AgentBox](https://shenxianpeng.dev/agentbox/) | 一个开源智能体平台的文档 | 纯文档站点：侧边栏、页内目录、卡片、表格和代码 |
| [立陶宛生活指南](https://lt.shenxianpeng.dev/) | 面向中文读者的立陶宛生活指南 | 中文界面和排版、带数据的首页、中文搜索、一本很长的参考书 |
{.compact}
