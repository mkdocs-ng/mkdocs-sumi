# 语言与中文排版

Sumi 的界面，包括按钮、标签、搜索面板、日期和提示框的默认标题，提供英文、简体中文和繁体中文三种语言。

```yaml title="mkdocs.yml"
theme:
  name: sumi
  locale: zh        # en、zh（zh_CN）、zh_TW
```

## 中文排版

当页面语言是中文、日文或韩文时，Sumi 会换用适合该文字的系统字体栈，稍微加大行高，并取消标题的字间距。所有字体都来自读者的操作系统，不会下载任何中文字体文件，页面依然轻量。

日期按语言格式化：英文显示为 *November 1, 2026*，中文显示为 *2026年11月1日*。

## 中文搜索

搜索按子串匹配中日韩文字，所以搜“配置”能找到“站点配置”“配置项”等任何包含这两个字的标题和正文，不需要分词插件，也不需要服务器。按 <kbd>⌘</kbd> <kbd>K</kbd> 打开搜索；输入 `>` 切换到命令模式，命令也支持中文关键词，例如 `>语言`、`>版本`。

## 提示框标题

提示框的默认标题跟随语言：`> [!TIP]` 在英文中显示为 *Tip*，在中文中显示为 *提示*。自定义标题总是按原样显示：

```markdown
> [!WARNING] 升级前请备份
> 0.x 版本之间的配置可能不兼容。
```

## 双语站点

每种语言构建一个 MkDocs 站点，再用 `extra.alternate` 把它们连起来。页眉会出现语言菜单，命令面板里也会出现“切换到 …”命令。本站就是这样做的：英文版在根目录，中文版在 `/zh/`。

1. 在英文配置中声明所有语言

    ```yaml title="mkdocs.yml"
    site_url: https://example.com/

    extra:
      alternate:
        - name: English
          link: https://example.com/
          lang: en
        - name: 简体中文
          link: https://example.com/zh/
          lang: zh
    ```

2. 新建一个继承英文配置的中文配置

    ```yaml title="mkdocs.zh.yml"
    INHERIT: mkdocs.yml
    site_url: https://example.com/zh/
    docs_dir: docs-zh
    site_dir: site/zh
    theme:
      locale: zh
    ```

3. 先构建英文，再构建中文

    ```sh
    mkdocs build
    mkdocs build -f mkdocs.zh.yml
    ```
{.steps}

`INHERIT` 会合并字典型配置，所以中文配置只需写不同的部分；`nav` 之类的列表会整体替换。把整个 `site/` 文件夹部署出去，两种语言就都上线了。

> [!TIP]
> 还没翻译的页面可以在中文 `nav` 里直接写英文页面的完整 URL，读者点击后会跳到英文版。本站的组件参考页就是这样处理的。

[sumi-starter](https://github.com/mkdocs-ng/sumi-starter) 模板仓库已经按这个结构配好了中英文两套内容和 GitHub Pages 部署流程。

## 添加新语言

界面字符串都在一个 Python 文件 `mkdocs_sumi/i18n.py` 中，缺失的字符串会回退到英文。欢迎提交新语言的 Pull Request。
