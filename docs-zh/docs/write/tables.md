# 表格

表格就是标准的 GitHub 风格 Markdown。Sumi 给它们加上边框和吸顶表头，在窄屏上可以横向滚动。

| 命令 | 用途 |
| --- | --- |
| `mkdocs new` | 新建项目 |
| `mkdocs serve` | 启动自动刷新的预览服务器 |
| `mkdocs build` | 构建站点 |
| `mkdocs gh-deploy` | 构建并部署到 GitHub Pages |

## 样式 {#variants}

在属性行上加一个或多个类名：

| 类名 | 效果 |
| --- | --- |
| `.wide` | 表格占满内容区的全部宽度 |
| `.compact` | 减小单元格内边距，适合密集数据 |
| `.striped` | 隔行加底色 |
| `.center` | 所有单元格居中 |
| `.expand` | 总是提供全屏阅读按钮（见下文） |
{.compact .striped}

## 宽表格 {#wide-tables}

比内容栏更宽的表格可以横向滚动，下方还会出现一个 **展开表格** 按钮。点它会全屏打开表格，表格占满整个窗口，表头始终可见。即使表格放得下，也可以加上 `.expand` 来提供这个按钮，比如下面这个表格：

| 选项 | 类型 | 默认值 | 作用范围 | 起始版本 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `palette` | 字符串 | `auto` | 所有页面 | 0.1 | `light`、`dark` 或 `auto`；读者自己选之前跟随操作系统 |
| `accent` | 字符串 | `vermilion` | 链接、高亮、当前标签 | 0.1 | 内置强调色（深色模式下有单独调校的版本），或任意 CSS 颜色（两种模式通用） |
| `bilingual_view` | 布尔值 | `true` | 有译文的页面 | 0.3 | 原文和译文左右并排，滚动时两边保持同步 |
| `comments` | 映射 | | 文档页和博客文章 | 0.3 | 页面下方的 Giscus 评论，读者滚动到附近时才加载 |
{.compact .expand}

## 对齐 {#alignment}

列对齐使用标准的冒号语法：

```markdown
| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| a | b | 1.00 |
```

| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| a | b | 1.00 |
| 较长的文字 | c | 120.50 |

> [!TIP]
> 列出选项和参数时，请用[字段](fields.md)，而不是很宽的表格。
